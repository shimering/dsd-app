# Earlier DSDapp planning retained for reference

Recovered from the Codex chat **Plan AI smile design app**, the original checkout `D:\AI Apps\DSD app`, and its committed research/deployment notes. Original repository history is retained in this checkout; the live `main` branch is not replaced by `rebuild-v2`.

Earlier decisions: an English, dentist-led web prototype; full desktop and phone access with light/dark themes; local photos plus owner-scoped Supabase structured records; explicit consent for photo AI requests; Gemini assistance and optional image simulation; a built-in tooth gallery with individual customization; and dental-smile planning inspired by the earlier DSD workflow.

Earlier plans also covered periodontal measurements, gingival design/gingivectomy, clinical consultation, treatment plans and PDF reports, video frame capture, and diagnostic prompts. Those features are deferred under the latest approved Smile Studio plan. Their historical research is preserved in [DSD_CLINICAL_RESEARCH.md](DSD_CLINICAL_RESEARCH.md), alongside legacy deployment and verification notes.

The latest approved upper-arch count is **ten teeth, FDI 15–25**, superseding an earlier six-tooth selection. The latest model defaults are `gemini-3.8-flash` for assistance and `gemini-3.1-flash-image` for rendering; prior model recommendations are historical.

Current sequence: **Photos → Measure → Lip outline → Teeth → Compare**, with reviewable working previews and advanced clinical features left on the roadmap. User corrections: premolars need one visible pointy buccal cusp; all ten teeth need a more rounded cervical contour; and tooth alignment must be checked independently of generated atlas cell spacing.
